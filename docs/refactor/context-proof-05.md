## Reproduction And Limits

Use a Git archive for each source, replace only its root AGENTS with that snapshot's project
template plus the identical exercise facts, add the local script rule and seed the one flag.
Give the same D/B/R packet to separate delegates without sharing their conclusions. Record
full versus selected reads, reuse, retained rules, omissions, commands and outcomes. Compare
D's corrected file against the unseeded source to prove that no other instruction changed.
The source-union counts are reproducible; delegate read descriptions remain reported exercise
observations, not instrumented model-context measurements. Do not promote this to an adopter
or model cost benchmark. A real FastAPI implementation/review pilot remains stage 09.
